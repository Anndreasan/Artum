ARTUM — CLEAN IMAGE SYSTEM

The old CSS-generated image system has been removed.

ALL REAL IMAGES ARE NOW REFERENCED WITH:
    <img src="images/filename.ext" alt="...">

Put every future image directly inside:
    images/

Example:
    images/nord-001.jpg
    images/lume.jpg
    images/detalj.avif

To replace a picture, only change the filename in the HTML <img src="...">.
The CSS controls the size/crop and will not create or replace the image.
